Bias-Variance Decomposition of Indian Elections

Every Indian election cycle produces the same ritual: exit polls drop hours before results, television panels argue over whose number is closest, and a day later half of them are dramatically, embarrassingly wrong. 2004's "India Shining" collapse and 2024's herd toward a 400+ NDA tally are the two most cited examples. The standard explanation is "the polls were biased."

Heuristic: Election exit poll failure isn't random noise; it's systematic. This notebook decomposes the Indian Lok Sabha exit-poll error into bias² (everyone wrong in the same direction) and variance (pollsters disagreeing with each other), using the classic ML bias-variance identity: If error is bias-dominated, the intuitive fix of "just average more polls" doesn't work, because averaging cancels independent noise, not a shared bias.     1. The parties involved are real (BJP/NDA, Congress/INC); the point of this notebook is exit-poll methodology, not commentary on outcomes.

Bias vs. variance

In machine learning, prediction error splits cleanly into two independent sources:

  • Bias - being wrong in the same direction, consistently. Every model (or every pollster) makes the same kind of mistake.
  • Variance - disagreeing with each other. No consistent direction, just noise and instability between different attempts. The distinction matters because the fix for each is completely different. Averaging many predictions together cancels out variance- that's the whole premise of a "poll of polls." But averaging does nothing for bias: if every pollster is wrong in the same direction, their average is also wrong in that direction. You can't average your way out of a shared blind spot.

So the real question isn't "Were the polls wrong" -it's "were they wrong independently?" Those require entirely different remedies, and only one of them is fixed by "just polling more people."

def normalize_agency(name):
    '''Loose normalization so the same firm from either source lines up.'''
    return (name.lower()
                .replace('.', '')
                .replace("today's", 'todays')
                .strip())

def canonicalize(election, schema):
    '''Map an election record from either schema onto NDA/INC/LEFT/OTH.'''
    year = election['election_year']
    actual = election['actual_results']
    polls = {}
    for p in election['exit_polls']:
        pred = p['predictions']
        agency = normalize_agency(p['agency'])
        polls[agency] = {
            'NDA': pred[schema['NDA']],
            'INC': pred[schema['INC']],
            'sample_size': p.get('sample_size'),
        }
    return {
        'year': year,
        'actual_NDA': actual[schema['NDA']],
        'actual_INC': actual[schema['INC']],
        'polls': polls,
    }

Bias-variance decomposition per election

For each election, treat the NDA seat predictions from all pollsters as draws of an estimator $\hat y$, and the actual NDA seat count as the truth $y$.

$$ \mathbb{E}[(\hat y - y)^2] = (\mathbb{E}[\hat y] - y)^2 + \mathbb{E}[(\hat y - \mathbb{E}[\hat y])^2] $$

$$ \text{MSE} = \text{Bias}^2 + \text{Variance} $$

def bias_variance_decomposition(actual, poll_predictions):
    predictions = np.array(list(poll_predictions.values()), dtype=float)

    mean_prediction = predictions.mean()
    bias = mean_prediction - actual
    variance = predictions.var()  # population variance, ddof=0
    individual_errors = predictions - actual
    mse = bias ** 2 + variance

    bias_fraction = bias ** 2 / mse if mse > 0 else 0.0
    variance_fraction = variance / mse if mse > 0 else 0.0

    return {
        'bias': bias, 'variance': variance, 'mse': mse,
        'bias_fraction': bias_fraction, 'variance_fraction': variance_fraction,
        'mean_prediction': mean_prediction, 'actual': actual,
        'individual_errors': individual_errors, 'n_polls': len(predictions),
    }

Which pollsters are consistently biased, and which way?

def pollster_bias_profile(elections_data):
    pollster_errors = defaultdict(list)
    for e in elections_data:
        actual = e['actual_NDA']
        for agency, v in e['polls'].items():
            pollster_errors[agency].append(v['NDA'] - actual)

    profiles = {}
    for agency, errors in pollster_errors.items():
        errors = np.array(errors)
        profiles[agency] = {
            'mean_error': errors.mean(),   # + = overestimates NDA on average
            'std_error': errors.std(),
            'n_elections': len(errors),
            'consistency': errors.mean() / errors.std() if errors.std() > 0 else np.nan,
        }
    return pd.DataFrame(profiles).T.sort_values('mean_error')

Is the bias statistically correlated across elections?

Important caveat first: this test runs on n = 8 elections. A one-sample t-test at n=8 has very low power, and an autocorrelation on 7 consecutive pairs is close to meaningless as "proof" of anything. Still I report these numbers, we don't lean on them as statistically significant confirmation.

def test_bias_correlation(elections_data):
    biases = []
    for e in elections_data:
        nda_preds = {a: v['NDA'] for a, v in e['polls'].items()}
        d = bias_variance_decomposition(e['actual_NDA'], nda_preds)
        biases.append(d['bias'])

    t_stat, p_value = stats.ttest_1samp(biases, 0)
    autocorr = np.corrcoef(biases[:-1], biases[1:])[0, 1] if len(biases) > 2 else np.nan

    return {
        'biases_by_year': dict(zip([e['year'] for e in elections_data], biases)),
        'mean_bias': np.mean(biases), 'bias_std': np.std(biases),
        't_statistic': t_stat, 'p_value': p_value, 'autocorrelation': autocorr,
        'n_elections': len(biases),
    }

corr_result = test_bias_correlation(elections)

Herding

Indian exit polls are released simultaneously - every firm airs its numbers the same evening voting ends, not on a rolling schedule over weeks. That rules out a "herding-over-time" trend chart (there's no "weeks before the election" axis for a same-day release; building one would mean inventing timestamps that don't exist for this kind of poll).

What we can measure directly from data already in hand is herding within that single release window: do pollsters converge on suspiciously similar numbers on the same evening? A simple proxy is the coefficient of variation (std / |mean|) of that election's NDA predictions low CV alongside high bias means "everyone agreed, and everyone was wrong."

SA little ML modelling: can historical bias be learned and corrected?

The project's open research question: if we know each pollster's historical bias, can a debiased ensemble beat a naive average?

This is a small, honest version of that idea a learned, leave-one-election-out bias correction, not a black-box model, so it's easy to see exactly what it's doing and where it can fail:

  1. For each held-out election, and each pollster present in it, compute that pollster's mean error on every other election (never touching the held-out year this is a leave-one-out split, not fitting and testing on the same data).
  2. Correct that pollster's prediction in the held-out year by subtracting the learned bias.
  3. Average the corrected predictions → the "debiased ensemble" prediction for that year.
  4. Compare its error against the naive (uncorrected) ensemble mean.

Pollsters with no other election in the dataset can't get a leave-one-out correction (there's nothing to learn from), so they fall back to their raw prediction in this comparison worth stating plainly rather than silently dropping them.

def leave_one_out_debiased_ensemble(elections_data):
    rows = []
    for i, held_out in enumerate(elections_data):
        train_elections = elections_data[:i] + elections_data[i+1:]

        train_errors = defaultdict(list)
        for e in train_elections:
            actual = e['actual_NDA']
            for agency, v in e['polls'].items():
                train_errors[agency].append(v['NDA'] - actual)
        learned_bias = {a: np.mean(errs) for a, errs in train_errors.items()}

        actual = held_out['actual_NDA']
        raw_preds, corrected_preds = [], []
        for agency, v in held_out['polls'].items():
            pred = v['NDA']
            raw_preds.append(pred)
            correction = learned_bias.get(agency, 0.0)  # 0 correction if never seen before
            corrected_preds.append(pred - correction)

        naive_mean = np.mean(raw_preds)
        debiased_mean = np.mean(corrected_preds)

        rows.append({
            'year': held_out['year'],
            'actual': actual,
            'naive_ensemble_pred': naive_mean,
            'naive_error': naive_mean - actual,
            'debiased_ensemble_pred': debiased_mean,
            'debiased_error': debiased_mean - actual,
        })
    return pd.DataFrame(rows).set_index('year')

Read this result cautiously, not triumphantly:

  • With only 8 elections and lots of one-election-only pollsters, the leave-one-out correction has very little training signal - for many pollster/year combinations it's learning a "bias" from a single other data point, which is barely better than guessing.
  • 2004 and 2024 are the hard cases precisely because they're the least "learnable" ones - the whole industry was wrong together, including firms whose other elections looked fine. A per-pollster historical correction can't fix a cycle-specific shared shock (an unusually large "shy voter" or late-swing effect that year); it can only correct pollsters who are chronically, individually biased.
  • This is a proof-of-concept for the idea in the project doc's "Research Question" section, not a validated forecasting method a real version would need far more elections, out-of-sample state elections, and probably firm-specific correction that also learns from methodology (sample size, mode of interview), not just historical error.

Bottom line, stated at the confidence the data actually supports:

  • Poll error is not uniformly bias-dominated; it clusters into two groups: elections where pollsters mostly disagreed with each other but weren't collectively wrong (variance-dominated), and elections where pollsters agreed with each other and were all wrong together (bias-dominated: 2004 and 2024 stand out clearly in this dataset).
  • When bias dominates, it's large, consistent with the paper's central claim that "More polls" doesn't help in those years because the disagreement between polls was never the problem.
  • The n=8 correlation test is suggestive, not confirmatory- don't oversell it.
  • A naive historical bias correction only partially helps, and specifically fails on exactly the elections (2004, 2024) where it would matter most, because those look like shared, cycle-specific shocks rather than chronic individual-pollster bias.
  • None of this is meaningful evidence about polling methodology in general, or about any named organization's competence, until the underlying numbers are verified against ECI results and original published poll figures that -remains the single biggest open item before any of this goes into a public write-up.
